🛒 Excel E-Commerce Sales Dashboard

📌 Project Overview
An interactive Excel dashboard built to analyze E-Commerce sales performance using Pivot Tables, Charts, KPI Cards, and Slicers.

📷 Dashboard Preview
![Dashboard](Dashboard.png)

✨ Features
📊 Interactive Dashboard
📈 Monthly Sales Trend Analysis
💰 Total Sales KPI
💵 Total Profit KPI
🛍️ Total Orders KPI
📦 Sales by Category
🌍 Sales by Region
🚚 Sales by Shipping Mode
📊 Profit by Category

🛠️ Tools Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Excel Formulas
Conditional Formatting

📊 Key Insights
📈 Electronics generated the highest sales.
🌍 North region recorded the highest revenue.
🚚 Standard Shipping was the most preferred shipping mode.
💰 January achieved the highest monthly sales.
📉 Office Supplies contributed the lowest sales and profit.
